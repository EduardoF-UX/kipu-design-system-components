# Kipu EMR Prototype

A functional prototype replicating the Kipu EMR (Electronic Medical Record) interface for UpliftDoctorOrder.

## Overview

This prototype recreates the exact visual design and layout of the Kipu EMR system, including:

- **Purple gradient header** with Kipu EMR branding
- **Multi-level navigation** with main tabs and sub-navigation
- **Patient information section** with detailed patient data
- **Medications and Action Orders tables** with interactive features
- **Filter and search functionality**
- **Responsive design** for different screen sizes
